# WhereDidI

WhereDidI is an external memory for the little things people forget: where an item is, who has it, and why it matters.

## Run locally

```bash
npm install
npm run dev
```

## MVP features

- Clean responsive dashboard UI
- Search memories with natural phrases
- Quick example prompts
- Category and pinned-memory filters
- Pin memories for quick access
- Capture new memories with localStorage persistence
- Empty-state handling for no results

## Hackathon demo

1. Search for `passport` to show a saved memory.
2. Click **Capture a memory** and add a new note.
3. Pin the new item.
4. Refresh the page to show that memories persist locally.
